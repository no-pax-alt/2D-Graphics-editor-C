Project Walkthrough

This project is a menu-driven 2D Graphics Editor developed in C using a 2D character array as the drawing canvas.

The application allows users to create and manage graphical objects such as rectangles, circles, lines and triangles. Each object is assigned a unique ID for identification and modification.

The editor supports adding, deleting, moving, resizing and cloning objects. Advanced features such as Object Inspector, Statistics Dashboard, Undo/Redo functionality, Save/Load operations and Template Generation have also been implemented.

Drawing operations are performed on a character-based canvas and displayed in the terminal. The project follows a modular design using separate source and header files.
