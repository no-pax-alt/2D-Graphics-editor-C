 Write a terminal-based 2D Graphics Editor in C split across three files: `graphics.h` (declarations, enums, structs), `graphics.c` (implementations), and `main.c` (menu loop, input validation). The canvas must be a 60x30 character grid initialized with '.' and printed with row/column axis coordinates labeled every 5 indices. Store shapes dynamically in a singly linked list using `Node` and `Object` structures containing fields for an auto-incremented ID, ShapeType enum (RECT, CIRCLE, LINE, TRIANGLE), coordinates (x,y,x2,y2,x3,y3), dimensions (w,h,radius), symbol character, fill flag, string label, Theme preset enum (CLASSIC='*', BLOCK='#', TECH='@', ARTISTIC='%'), creation time, and edit count. Implement all drawing algorithms from scratch: DDA for line drawing, Bresenham's Midpoint algorithm for circle outlines (with a stack-based flood-fill on an isolated temporary canvas for circle filling), nested loops for rectangles, and a scanline interpolation fill (sorting vertices by y-coordinate) for triangles. Provide operations to add, delete (confirming with the user beforehand), search, move, resize, clone (deep-copying with a new ID), and group-move (translating all objects together). Implement full undo and redo histories with separate stacks of depth 15 containing deep copies of the list and canvas. Perform Axis-Aligned Bounding Box (AABB) overlap detection after every draw, printing a collision warning if shapes cross. Build composite templates for a House, Tree, Rocket, and Arrow that register multiple individual sub-objects. Implement CSV file saving/loading (which must keep the current state intact on parse failure) and a silent auto-save every 5 operations. Print a box-bordered Statistics Dashboard tracking fill percentage, symbol usage, edits, session duration, and undo counts, alongside a formatted Object Inspector table listing timestamps and overlapping IDs. Run the program using a robust 17-option menu validated against crashes using `fgets` and `sscanf`. Ensure the code compiles cleanly under `gcc -Wall -Wextra` without warnings.
